# smartcrop-updated

SmartCrop AI — Precision Agriculture Platform for Modern Farming.

## Features
- **Modern Agrovia UI/UX**: Dual responsive design tailored for both Desktop Website and Mobile App viewports.
- **AI Crop Pathology & Diagnostics**: Identify diseases with severity indicators and spray dosages.
- **Evapotranspiration & Water Budgeting**: Calculate crop water volume and pump runtimes.
- **Live Mandi Commodity Intelligence**: APMC market tickers, MSP benchmarks, and revenue forecasting.
- **24/7 AI Agronomist Chatbot**: Instant contextual agricultural assistance.
- **Interactive Seasonal Crop Calendar & Soil Profiling**: Dynamic scheduling for Kharif, Rabi, and Zaid cultivation.

## Tech Stack
- **Frontend**: React 18, Vite, Vanilla CSS design system, Google Fonts (`Plus Jakarta Sans` & `Playfair Display`).
- **Backend**: Spring Boot 3.2, Spring Security, JWT, JPA, Hibernate, REST APIs.
